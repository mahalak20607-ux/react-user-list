# React User List

A simple React application that fetches user data from the JSONPlaceholder API and displays it in a table.

## Features

- Fetches users using `fetch()`
- Uses React `useState`
- Uses React `useEffect`
- Displays User ID
- Displays Name
- Displays Username
- Displays Email
- Loading state
- Error handling

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- JSONPlaceholder API

## API Used

JSONPlaceholder:

https://jsonplaceholder.typicode.com/users

## How to Run

1. Clone the repository
2. Open the project folder in VS Code
3. Install dependencies:

```bash
npm install
````

4. Start the development server:

```bash
npm run dev
```

5. Open the localhost URL shown in the terminal.

## Output

The application displays a table containing 10 users with their:

* ID
* Name
* Username
* Email
